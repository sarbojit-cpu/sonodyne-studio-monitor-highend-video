# Sonodyne Studio Series — long-form voiceover script

**Tone: Option A — Warm and Trustworthy** (brief Section 9), chosen because it
sustains engagement across a ~10-minute educational-sales runtime better than
the clinical Option B or the abstract Option C, for a mixed audience of working
professionals and serious enthusiasts. One tone throughout — no mixing.

This is new copy written in that tone from the brief's Section 3
customer-psychology material — not the PDF's sample passages read verbatim.
English only. Word counts are budgeted at ~140–150 wpm against each segment's
runtime, with headroom left for the music to breathe.

**Status:** the video is delivered with on-screen text carrying the full
narrative and the synthesized soundtrack embedded. TTS generation was not
possible in the build environment (no ElevenLabs/API credentials, audio
endpoints blocked by the network allowlist — same block documented in
AUDIO.md). This script is timed and ready: generate per-segment audio with
`tools/voiceover.py --scene-dir` (ElevenLabs or Qwen3-TTS), then lay each
file at its segment's start time below. On-screen spec callouts already land
where the script mentions them.
